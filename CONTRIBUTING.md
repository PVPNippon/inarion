# Contributing to the Project

We welcome community contributions to improve this project.

However, please read and understand the following conditions before submitting a pull request.

## License and Usage Reminder

This is a **source-available** project licensed for **non-commercial use only** .

By contributing to this repository:

- You agree that your contribution will be **licensed under the same license as the project** (non-commercial, source-available).
- You grant PVP Inc the right to use, modify, and distribute your contributions-including in future commercial license, products, or offerings.

If you do not agree to these terms, **do not submit a pull request**.

## How to Contribute

1. **Fork** the repository.
2. Create a new branch from `main`.
3. Make your changes.
4. Submit a **Pull Request** with a clear description of your changes and why they are needed.
5. Sign the Contributor License Agreement (CLA) when prompted via GitHub bot.
